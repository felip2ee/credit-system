# ai — OpenAI credit opinion ("parecer") generation

Server-only wrapper around the OpenAI Chat Completions API that turns bureau data into a structured credit opinion. Security-sensitive: it reads `OPENAI_API_KEY` and sends personal and credit data to a third party.

## Responsibility

Belongs here: the model call and output validation (`opinion.ts`), the system prompts and payload builders (`prompt.ts`) and the prompt reference doc (`parecer-prompt.md`). Does NOT belong here: the output schema (`ParecerSchema` in `src/types/ai.ts`), the stored admin-edited prompts (`settings` table), PDF rendering (`src/lib/pdf/`) and persistence of opinions.

## Key patterns

- `runParecer()` in `opinion.ts` is the shared core. `generateParecer` (PF/PJ) and `generateCompanyParecer` (group, 16000 output tokens) only differ by prompt and payload builder.
- Output is requested as `json_object`, then `JSON.parse` and `ParecerSchema.safeParse`. `finish_reason === "length"` gets its own error, because truncated JSON would otherwise surface as "invalid JSON".
- `supportsTemperature()` sets `temperature` only for `gpt-3|4` models; reasoning models reject it.
- `prompt.ts` holds `SYSTEM_PROMPT_PF`, `SYSTEM_PROMPT_PJ`, `COMPANY_SYSTEM_PROMPT`, `buildUserPayload`, `buildCompanyPayload`, and versions (`PROMPT_VERSION`, `COMPANY_PROMPT_VERSION`).
- Admin overrides arrive as the optional `systemPrompt` argument; keys come from `aiPromptKey(kind)` (`ai_prompt_<kind>`) with defaults in `DEFAULT_AI_PROMPTS`.
- The model is chosen by `OPENAI_MODEL` (default `gpt-4o`), exported as `OPENAI_MODEL` from `prompt.ts`.

## Local conventions

- Bump `PROMPT_VERSION` / `COMPANY_PROMPT_VERSION` when a prompt changes in a way that affects output.
- Keep `parecer-prompt.md` and `prompt.ts` consistent; `prompt.ts` is the source of truth.
- Prompts and user-facing errors are pt-BR.
- Server-only: never import from client components.
