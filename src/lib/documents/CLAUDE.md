# documents — ClamAV scan client and private file storage

Low-level pieces for untrusted uploads: a ClamAV scan client and a private filesystem store. Security-sensitive: handles untrusted files and personal documents.

## Responsibility

Belongs here: the ClamAV INSTREAM client (`clamav.ts`) and the filesystem layer (`storage.ts`). No upload service and no download route exist in this tree yet. Does NOT belong here: authorization decisions or the config source (`@/lib/config`). Only the relative object key leaves this module; absolute paths do not.

## Key patterns

- `writeQuarantine` stores an upload under `quarantine/`. `scanStream` checks it with ClamAV. `commitQuarantine` moves it to `objects/`.
- The scanner fails CLOSED: any timeout, connection error or bad reply throws `ScannerUnavailableError`; an unscanned file is never accepted.
- `removeQuarantine` deletes a rejected upload. `removeObject` deletes a committed object by key.
- `openObject` and `removeObject` resolve the key under `objects/` and refuse traversal.
- Object key is `<first two chars>/<id>` under `objects/` (`objectKey`).
- `scanStream` takes `ScanOptions`; `scannerVersion` reads the ClamAV version.

## Local conventions

- Throw `ScannerUnavailableError` for scanner failures; never accept the file.
- Magic-byte and MIME checks are not in this module; add them with the upload service.
- Tests (none yet) should use temp dirs and a fake ClamAV TCP server; no real scanner or network.
- Server-only; paths come from `config.documentRoot`, never from caller input.
