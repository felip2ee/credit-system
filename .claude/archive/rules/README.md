# Archive

Claude Code does not load this folder. It is kept for reference only.

`ecc/common` was archived because it conflicts with the project rules:
- It requires 80% coverage and TDD. The project rule is "test what can break" (`05-testing.md`).
- It requires a review per change. The project rule is one review per finished issue.
- It names agents that do not exist here (`typescript-reviewer`, `python-reviewer`, `go-reviewer`, `rust-reviewer`).
- It forbids the `bypassPermissions` mode.
