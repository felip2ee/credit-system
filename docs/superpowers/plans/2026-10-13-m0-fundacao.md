# M0 — Fundação Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um servidor novo, sem dados, sobe com `docker stack deploy`, aplica o schema, cria o superadmin e funciona; dev sobe com `docker compose` + `npm run dev`; CI prova tudo contra Postgres 18 real.

**Architecture:** Corrige bloqueadores de infraestrutura e schema encontrados na review, remove o caminho de migração Supabase e os módulos fora do produto, adiciona bootstrap do superadmin no hook `instrumentation` do Next.js e um gerador de configuração de produção em Python (stdlib) que separa valores não secretos (`.env.production`) de Docker secrets.

**Tech Stack:** Next.js 14.2 (App Router, standalone), Better Auth 1.7.2, PostgreSQL 18.6 (RLS), node-postgres 8.21, Vitest 4, node:test, Python 3.10+ (stdlib, unittest), Docker Swarm, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-13-m0-fundacao-design.md` (produto: `docs/superpowers/specs/2026-10-13-plataforma-bureau-produto-design.md`). Issues: #4–#12.

## Global Constraints

- Imagem do banco: `postgres:18.6-alpine3.23`; volume montado em `/var/lib/postgresql` (nunca `/var/lib/postgresql/data`).
- Dev: Postgres em `127.0.0.1:54329`, banco `credit_system`, superusuário `postgres`, todas as senhas de dev = `test`.
- `db/migrations/` é base editável até o primeiro deploy de produção: corrigir arquivos existentes, não empilhar migrations de correção.
- Valores secretos nunca em argv de processo, nunca em `.env.production`, nunca em logs.
- Senha do superadmin: 12–128 caracteres (mesmo limite do Better Auth em `src/lib/auth/config.ts`).
- O superadmin do M0 tem papel `admin`; nunca sobrescrever usuário existente.
- Script Python: somente biblioteca padrão, Python ≥ 3.10.
- Textos para o usuário final em português.
- Commits terminam com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. `SUPERADMIN_EMAIL` com maiúsculas/espaços (`" Felipe@X.com "`) quando já existe `felipe@x.com` → deve ser tratado como existente, sem duplicar (Task 5).
2. Duas réplicas do app sobem ao mesmo tempo → exatamente um superadmin criado, nenhuma falha (Task 5).
3. Valores não secretos com espaços, `<`, `>`, aspas ou `$` (ex.: `SMTP_FROM=Rainha do Crédito <no-reply@x.com>`) → `.env.production` precisa sobreviver a `set -a; . ./.env.production` sem quebrar nem expandir (Task 6).
4. Rodar o script de setup de novo num servidor já configurado → não sobrescreve `.env.production` sem `--force`, pula secrets existentes com aviso, não cria nada em `--dry-run` (Task 6).
5. `npm run db:reset` apontado para produção → recusa (`NODE_ENV=production` ou host fora de localhost/127.0.0.1/::1) (Task 1).

- [ ] **Step 3: Implementar `scripts/db/reset.mjs`**

```js
// Dev-only: drops and recreates the public schema, then reapplies every
// migration. Refuses anything that is not a local database.
import { pathToFileURL } from "node:url";
import { resolve } from "node:path";

import pg from "pg";

import { hydrateSecretEnv } from "../../src/lib/runtime-secrets.mjs";
import { migrate } from "./migrate.mjs";

const LOCAL_HOSTS = new Set(["localhost", "127.0.0.1", "[::1]", "::1"]);

export function assertResettable(connectionString, env) {
  if (!connectionString) throw new Error("DATABASE_OWNER_URL is required");
  if (env.NODE_ENV === "production") {
    throw new Error("db:reset refuses to run with NODE_ENV=production");
  }
  const host = new URL(connectionString).hostname;
  if (!LOCAL_HOSTS.has(host)) {
    throw new Error(`db:reset only runs against a local database (got host "${host}")`);
  }
}

export async function reset(connectionString = process.env.DATABASE_OWNER_URL, env = process.env) {
  assertResettable(connectionString, env);
  const client = new pg.Client({ connectionString });
  await client.connect();
  try {
    await client.query("drop schema public cascade");
    await client.query("create schema public");
    await client.query("alter schema public owner to pg_database_owner");
  } finally {
    await client.end();
  }
  await migrate(connectionString);
}

if (process.argv[1] && pathToFileURL(resolve(process.argv[1])).href === import.meta.url) {
  hydrateSecretEnv(process.env);
  reset().catch((error) => {
    console.error(error instanceof Error ? error.message : error);
    process.exitCode = 1;
  });
}
```

Note: `migrate.mjs` calls `hydrateSecretEnv` at import time; that is harmless here.

```ts
// Creates the platform superadmin on first start of an empty database.
// Never touches an existing user: after the first boot the password belongs to
// the user (changed through the app), and the env/secret may be removed.
import { randomUUID } from "node:crypto";

import { hashPassword } from "better-auth/crypto";

import { writeAuditEvent } from "@/lib/audit/write";
import { withUserTransaction } from "@/lib/db/transaction";

type Env = Record<string, string | undefined>;
export type SuperadminOutcome = "disabled" | "exists" | "created";

const EMAIL = /^[^@\s]+@[^@\s]+\.[^@\s]+$/;

export async function ensureSuperadmin(env: Env = process.env): Promise<SuperadminOutcome> {
  const email = env.SUPERADMIN_EMAIL?.trim().toLowerCase();
  if (!email) return "disabled";
  if (!EMAIL.test(email)) throw new Error("SUPERADMIN_EMAIL must be a valid email");

  const password = env.SUPERADMIN_PASSWORD;
  if (!password) {
    throw new Error("SUPERADMIN_PASSWORD is required when SUPERADMIN_EMAIL is set");
  }
  if (password.length < 12 || password.length > 128) {
    throw new Error("SUPERADMIN_PASSWORD must be between 12 and 128 characters");
  }

  const id = randomUUID();
  const passwordHash = await hashPassword(password);

  return withUserTransaction({ userId: id, role: "admin" }, async (client) => {
    // Serialises concurrent replicas; the existence check must run under it.
    await client.query("select pg_advisory_xact_lock(hashtext('credit-system-superadmin'))");
    const existing = await client.query('select 1 from "user" where lower(email) = $1', [email]);
    if (existing.rowCount) return "exists";

    await client.query(
      'insert into "user" (id, name, email, email_verified, two_factor_enabled) values ($1, $2, $3, true, false)',
      [id, "Superadmin", email],
    );
    await client.query(
      "insert into account (id, issuer, account_id, provider_id, user_id, password) values ($1, 'local:credential', $2, 'credential', $2, $3)",
      [randomUUID(), id, passwordHash],
    );
    await client.query(
      "insert into profiles (id, auth_user_id, full_name, email, role) values ($1::uuid, $1::text, $2, $3, 'admin')",
      [id, "Superadmin", email],
    );
    await writeAuditEvent(client, {
      actorId: id,
      action: "superadmin.bootstrap",
      targetTable: "profiles",
      targetId: id,
    });
    return "created";
  });
}
```

```python
def valid_domain(v: str) -> bool:
    return bool(_DOMAIN.match(v.strip().lower()))

def valid_port(v: str) -> bool:

def valid_cidr(v: str) -> bool:
    if "/" not in v:
        return False
    try:
        ipaddress.ip_network(v, strict=False)
        return True
    except ValueError:
        return False


def valid_digest(v: str) -> bool:
    return v == "" or bool(_DIGEST.match(v))


def valid_superadmin_password(v: str) -> bool:
    return 12 <= len(v) <= 128

def gen_hex(nbytes: int = 24) -> str:
    return secrets.token_hex(nbytes)


def gen_password() -> str:

def build_secrets(provided: dict[str, str]) -> dict[str, str]:
    pg, owner, app, backup = gen_hex(), gen_hex(), gen_hex(), gen_hex()

def render_env(values: dict[str, str]) -> str:
    lines = [
        "# Gerado por scripts/setup/setup_production.py — valores NÃO secretos.",
        "# Deploy: set -a; . ./.env.production; set +a; docker stack deploy -c docker-stack.yml reino",
    ]
    lines += [f"{key}={shlex.quote(values.get(key, ''))}" for key in ENV_KEYS]
    return "\n".join(lines) + "\n"


def render_credentials(env_values: dict[str, str], secret_values: dict[str, str]) -> str:
    out = [
        "CREDENCIAIS DA PLATAFORMA — mova para um gerenciador de senhas e APAGUE este arquivo.",
        "Sem restic_password não há restauração de backup.",
        "",
        f"Superadmin: {env_values.get('SUPERADMIN_EMAIL', '')} / {secret_values['superadmin_password']}",
        "",
        "[Docker secrets]",
    ]
    out += [f"{name}={secret_values[name]}" for name in SECRET_NAMES]
    out += ["", "[.env.production]"]
    out += [f"{key}={env_values.get(key, '')}" for key in ENV_KEYS]
    return "\n".join(out) + "\n"


def default_runner(args: list[str], input: str | None = None) -> tuple[int, str]:
    result = subprocess.run(args, input=input, capture_output=True, text=True)
    return result.returncode, result.stdout


def detect_proxy_cidr(network: str, run: Runner = default_runner) -> str | None:
    code, out = run(["docker", "network", "inspect", network, "--format", "{{json .IPAM.Config}}"])
    if code != 0:
        return None
    try:
        for entry in json.loads(out or "[]"):
            subnet = entry.get("Subnet")
            if subnet and valid_cidr(subnet):
                return subnet
    except (ValueError, AttributeError):
        return None
    return None


@dataclass
class SecretReport:
    created: list[str] = field(default_factory=list)
    skipped: list[str] = field(default_factory=list)


def create_docker_secrets(values: dict[str, str], run: Runner = default_runner) -> SecretReport:
    report = SecretReport()
    for name in SECRET_NAMES:
        code, _ = run(["docker", "secret", "inspect", name])
        if code == 0:
            report.skipped.append(name)
            continue
        code, _ = run(["docker", "secret", "create", name, "-"], input=values[name])
        if code != 0:
            raise RuntimeError(f"falha ao criar o secret {name}")
        report.created.append(name)
    return report


def _write_private(path: Path, content: str, force: bool) -> None:
    flags = os.O_WRONLY | os.O_CREAT | (os.O_TRUNC if force else os.O_EXCL)
    fd = os.open(path, flags, 0o600)
    with os.fdopen(fd, "w", encoding="utf-8") as fh:
        fh.write(content)
    os.chmod(path, 0o600)


def write_outputs(out_dir: Path, env_values: dict[str, str], secret_values: dict[str, str], force: bool) -> None:
    env_path = out_dir / ".env.production"
    cred_path = out_dir / "credenciais-GUARDAR.txt"
    if not force:
        for path in (env_path, cred_path):
            if path.exists():
                raise FileExistsError(f"{path} já existe (use --force para sobrescrever)")
    _write_private(env_path, render_env(env_values), force)
    _write_private(cred_path, render_credentials(env_values, secret_values), force)


def apply(out_dir: Path, env_values: dict[str, str], secret_values: dict[str, str], run: Runner,
          dry_run: bool, no_docker: bool, force: bool) -> None:
    if dry_run:
        print("\n[dry-run] nada foi gravado. Seria criado:")
        print(f"  {out_dir / '.env.production'}")
        print(f"  {out_dir / 'credenciais-GUARDAR.txt'}")
        if not no_docker:
            print("  Docker secrets: " + ", ".join(SECRET_NAMES))
        return
    write_outputs(out_dir, env_values, secret_values, force)
    if not no_docker:
        report = create_docker_secrets(secret_values, run)
        if report.created:
            print("Secrets criados: " + ", ".join(report.created))
        if report.skipped:
            print("AVISO: já existiam e NÃO foram alterados (secrets do Swarm são imutáveis): "
                  + ", ".join(report.skipped))
            print("       Os valores em credenciais-GUARDAR.txt para esses nomes NÃO estão em uso.")


def ask(prompt: str, default: str, validator: Callable[[str], bool],
        input_fn: Callable[[str], str] = input) -> str:
    suffix = f" [{default}]" if default else ""
    while True:
        value = input_fn(f"{prompt}{suffix}: ").strip() or default
        if validator(value):
            return value
        print("  valor inválido, tente de novo.")


def ask_secret(prompt: str, validator: Callable[[str], bool],
               getpass_fn: Callable[[str], str] = getpass.getpass) -> str:
    while True:
        value = getpass_fn(f"{prompt}: ")
        if validator(value):
            return value
        print("  valor inválido, tente de novo.")


def collect(run: Runner, input_fn=input, getpass_fn=getpass.getpass) -> tuple[dict[str, str], dict[str, str]]:
    env_values: dict[str, str] = {}
    for key, prompt, default, validator in QUESTIONS:
        if key == "TRAEFIK_PROXY_CIDR":
            default = detect_proxy_cidr(env_values["TRAEFIK_NETWORK"], run) or ""
        env_values[key] = ask(prompt, default, validator, input_fn)
    provided = {name: ask_secret(prompt, validator, getpass_fn) for name, prompt, validator, _ in SECRET_QUESTIONS}
    return env_values, provided


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--dry-run", action="store_true", help="mostra o que faria, não grava nada")
    parser.add_argument("--no-docker", action="store_true", help="só grava os arquivos, não cria secrets")
    parser.add_argument("--force", action="store_true", help="sobrescreve .env.production e credenciais existentes")
    parser.add_argument("--output-dir", type=Path, default=Path.cwd())
    args = parser.parse_args(argv)

    env_values, provided = collect(default_runner)
    secret_values = build_secrets(provided)
    try:
        apply(args.output_dir, env_values, secret_values, default_runner,
              dry_run=args.dry_run, no_docker=args.no_docker, force=args.force)
    except FileExistsError as exc:
        print(f"ERRO: {exc}", file=sys.stderr)
        return 1

    if not args.dry_run:
        print("\nPróximos passos:")
        print("  1. Mova credenciais-GUARDAR.txt para um gerenciador de senhas e apague-o do servidor.")
        if not env_values["REINO_IMAGE_DIGEST"] or not env_values["REINO_BACKUP_DIGEST"]:
            print("  2. Preencha REINO_IMAGE_DIGEST e REINO_BACKUP_DIGEST em .env.production (resumo do workflow GHCR).")
        print("  3. set -a; . ./.env.production; set +a; docker stack deploy -c docker-stack.yml reino")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
